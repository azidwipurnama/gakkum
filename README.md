# Gakkum Network Monitor

Tool monitoring jaringan kantor dan denah ruangan real-time dengan FastAPI dan Next.js.

## Cara Instalasi & Penggunaan untuk Rekan Kantor

Cukup ikuti 2 langkah mudah berikut di terminal (PowerShell / Command Prompt):

### 1. Install Global
```bash
npm install -g gakkum
```

### 2. Jalankan Dasbor
```bash
gakkum
```

Perintah di atas akan secara otomatis menyiapkan *virtual environment* Python, menginstal *dependencies* backend, menyalakan server FastAPI, meluncurkan frontend Next.js, dan membuka browser ke halaman monitoring.
